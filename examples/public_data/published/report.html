Public-data case study: source, meaning and reproduction

Source: Kevin Arvai, Genetic Variant Classifications, Kaggle dataset kevinarvai/clinvar-conflicting version 2 (CC0: Public Domain). Original resource: NCBI ClinVar GRCh37 VCF downloaded by the dataset author on 2018-04-07. This is the same checksum-pinned snapshot used by ClinVar Conflict Explorer.

Dataset URL: https://www.kaggle.com/datasets/kevinarvai/clinvar-conflicting. Raw CSV SHA-256: 53061e207d437af397028760be5bc566d216f6932e21db5a10322b843c41689a.

Each sample is a variant, not a patient. The outcome is recorded classification disagreement in this historical multiple-submission snapshot. It does not label pathogenicity, disease, or disagreements arising in the future. Source categories combine benign/likely benign, VUS, and pathogenic/likely pathogenic; disagreement spans these categories.

65,172 variants across 2,328 gene groups were evaluated. Only three population frequency inputs are used, transformed independently with log1p(1,000,000 × frequency). Gene is a splitting constraint, never a predictor. Clinical assertions and review information are excluded. All five folds have both classes and zero train/test gene or ID overlap.

Mean average precision: model 0.299413, prevalence baseline 0.251995, absolute difference 0.047418. Mean ROC AUC: model 0.574151, baseline 0.500000. This is a modest internal ranking signal, not clinical validation. These estimates are sample-level, so genes with more variants contribute more observations. There is no temporal or external-cohort validation.

Cross-cohort expression evaluation remains pending: GSE10072 and GSE7670 share GPL96 probes and compatible tissue labels after exclusions, but released RMA and MAS5 values do not have a verified common preprocessing workflow. No expression cross-cohort scores are reported.

From the OmicsFold repository after local installation, reproduce with python examples/public_data/run_case_study.py --download --work-dir /path/to/new/outside-repository-work. Alternatively provide --raw-csv /path/to/clinvar_conflicting.csv. The script verifies the pinned checksum, prepares tables, invokes the installed omicsfold validate and omicsfold benchmark commands, and independently audits splits. Use an unused work directory. Raw downloads and full variant-level results remain outside Git.

This compact publication includes the HTML, fold metrics, exploratory coefficients, preparation provenance and split audit. Full predictions.tsv, splits.tsv and run.json are generated under the external work directory's results folder. The installed CLI report is otherwise unchanged; this case-study context is added by the reproduction script.
